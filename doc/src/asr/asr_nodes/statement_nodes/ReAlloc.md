# ReAlloc

Reallocates objects to a new shape, allocating them if needed.

## Declaration

### Syntax

```text
ReAlloc(alloc_arg* args)
```

### Arguments

| Argument | Description |
|----------|-------------|
| `args` | one [alloc_arg](../helper_nodes/alloc_arg.md) per object, with the new shape. |

### Return values

None.

## Description

**ReAlloc** exists for automatic reallocation on assignment: when the left
hand side of an assignment is an allocatable whose shape does not match the
right hand side, the object has to be deallocated and allocated again. Unlike
[Allocate](Allocate.md), it is not an error for the object to be allocated
already.

It is generated by the compiler rather than written by a user, and the
`realloc_lhs` member of [Assignment](Assignment.md) is what asks for it.

## Examples

```clojure
(ReAlloc
  :args [
    (alloc_arg
      :a (Var
        :v (SymbolRef 1 "a")
      )
      :dims [
        (dimension
          :start (IntegerConstant
            :n 1
            :type (Integer
              :kind 4
            )
            :intboz_type :Decimal
          )
          :length (IntegerConstant
            :n 20
            :type (Integer
              :kind 4
            )
            :intboz_type :Decimal
          )
        )
      ]
      :codims []
      :len_expr nil
      :sym_subclass nil
      :type nil
    )
  ]
)
```
