# arraybound

Which end of a dimension is asked for.

## Declaration

### Syntax

```text
arraybound = LBound | UBound
```

### Values

| Value | Meaning |
|----------|-------------|
| `LBound` | the lower bound, `lbound`. |
| `UBound` | the upper bound, `ubound`. |

### Return values

None. An enumeration value is not evaluated.

## Description

[ArrayBound](../expression_nodes/ArrayBound.md) is one node for both
intrinsics, distinguished by this member.
